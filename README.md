# gh300game
live demo for GH-300

## Shooting Reflex Game

A Python-based shooting reflex game that tests your reaction time!

### Features
- Enter your player name
- Shooter displayed at bottom middle of screen
- Random target appearance
- Test your reflexes by pressing SPACE when target appears
- Win if reaction time < 0.3 seconds
- Real-time feedback on your performance

### Installation

1. Install Python 3.7 or higher
2. Install dependencies:
```bash
pip install -r requirements.txt
```

### How to Play

Run the game:
```bash
python shooting_game.py
```

1. Enter your name and press ENTER
2. Wait for the target to appear on screen
3. Press SPACE as quickly as possible when you see the target
4. If your reaction time is less than 0.3 seconds, YOU WIN!
5. Otherwise, YOU ARE TOO SLOW
6. Press SPACE to play again or ESC to quit
